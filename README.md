# نقد الخطط وتصميم التعلم الأردني

حزمة مهارة ذكاء اصطناعي لمساعدة **مشرفي المنهاج والمشرفين التربويين والمعلمين** على نقد الخطط الفصلية وخطط الوحدات والدروس الأردنية، وتصميم بدائل قابلة للتنفيذ وقياس أثر تحسينها.

**الإصدار التجريبي: 0.1.0.** أداة تطوير مهني مقترحة؛ لم تصدر عن وزارة التربية والتعليم أو المركز الوطني لتطوير المناهج والتقويم، ولا تمثل اعتماداً رسمياً.

في Claude أضف ملف ZIP إلى قسم Skills ثم فعّل المهارة. يوضح [دليل Claude الرسمي](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) طريقة الرفع. يحتوي الأرشيف مجلد المهارة مباشرة، فلا حاجة إلى ضغطه من جديد. لا ينشئ رفع الملف اتصالاً بأدوات المنهاج الأردني؛ تستخدم المهارة المرفقات أيضاً.

## ماذا تقدم؟

| الوضع | المنتج |
|---|---|
| نقد خطة | قوة وفجوات موثقة، خريطة مواءمة، أولويات تحسين وتقدير عند كفاية الأدلة |
| تصميم وتحسين | خطة فصل/وحدة/درس تراعي النتاج والزمن والموارد والتقويم والإتاحة |
| قياس أثر | خط أساس وتجربة محدودة ومؤشرات تعلم ومراجعة للتعديل |

يفصل السلم بين جودة ما أمكن فحصه ونسبة الأدلة المتاحة. لا يُعطى صفر بسبب مرجع غير متاح، ولا يُفترض أن غياب توثيق عنصر يعني عدم تنفيذه في الصف. وتفحص الأداة الحسابية الحصص والروابط دون ادعاء الحكم الآلي على جودة التدريس.

محاور السلم السبعة: المطابقة ودقة المحتوى، والمواءمة، والتقويم، والتسلسل والطلب المعرفي، والإتاحة والتمايز، والزمن والتنفيذ، والابتكار والتأمل.

## مثال طلب للمشرف

> انقد الخطة المرفقة للصف […] في مبحث […]، الفصل […] والعام […]. المرجع والطبعة […]. المتاح […] حصة فعلية، والموارد […]. وثق الملاحظات بمواضعها، وافصل المتطلبات المحلية عن الاسترشاد العالمي. قدم أهم ثلاث تحسينات، ولا تحسم المطابقة الرسمية إذا غاب مرجعها.

أرفق الخطة والإطار/الكتاب ودليل المعلم المتاح ونموذج المدرسة، وما يهم من عدد اللقاءات والموارد. أزل أسماء الطلبة والبيانات الشخصية قبل إرفاق الأمثلة أو فتح مقترح تطوير عام.

## للمطورين

Python 3 دون حزم خارجية، من جذر المستودع:

```bash
python -m unittest discover -s jordan-curriculum-planning/evals -p 'test_*.py' -v
python jordan-curriculum-planning/scripts/plan_checks.py check jordan-curriculum-planning/assets/example-plan.json
python jordan-curriculum-planning/scripts/plan_checks.py score jordan-curriculum-planning/assets/example-ratings.json
python tools/build_release.py
```

الأمثلة اصطناعية وتتضمن فجوات مقصودة للاختبار؛ ليست نتاجات منهاج رسمية. [عقد البيانات](jordan-curriculum-planning/references/data-contract.md) يشرح المدخلات ودلالة النتائج.

## الأدلة وحدود الاستخدام

نجحت 12 حالة اختبار برمجية، وفحصت بنية المهارة وروابطها، وأُجريت مراجعة سلوكية مستقلة محدودة. يوجد [بنك من 14 سيناريو](jordan-curriculum-planning/evals/cases.json) مع [بروتوكول تقييم](jordan-curriculum-planning/evals/protocol.md)؛ لم تُنفّذ السيناريوهات كلها، ولم تُعاير الحزمة بعد على خطط أردنية حقيقية بمقيمين بشريين أو ببيانات تعلم صفية.

المراجع الدولية مصادر استرشاد وليست شروطاً مستوردة على جميع المباحث. بعض الوثائق الأردنية ظهرت في الفهرسة وتعذر جلبها بالكامل أثناء الإعداد؛ سُجل ذلك صراحة في [سجل المصادر](jordan-curriculum-planning/references/sources.md). لا تتضمن الحزمة بنك نتاجات رسميّاً لكل الصفوف أو تقويماً مدرسياً معتمداً جاهزاً.

## المساهمة المهنية

يمكن اقتراح تحسين عبر Issues أو Pull Requests، مع تحديد الصف والمبحث والطبعة وموضع الدليل، ووصف المشكلة والتحسين المقترح. استخدم أمثلة منزوعة الهوية ومواد تملك حق مشاركتها؛ يكفي رابط رسمي وموضع محدد بدلاً من إعادة نشر وثائق كاملة.

الأولوية التالية: معايرة السلم على 5–10 خطط تجريبية بمقيمين مستقلين، وفصل عينة التطوير عن عينة التحقق، ثم اختبار أثر التحسين داخل الصف. هذا عدد بداية تجريبية وليس دليلاً على تمثيل جميع المدارس.
