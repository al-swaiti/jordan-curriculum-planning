# بيانات المهمة

أرسل المتاح واترك غير المعلوم؛ لا حاجة إلى أسماء طلبة.

- المطلوب: نقد / فصل / وحدة / درس / تحسين / قياس أثر.
- الصف والمبحث والفصل والعام:
- الكتاب/الإطار/الدليل والطبعة أو المرفقات:
- الخطة الأصلية والنموذج المطلوب:
- النطاق: كامل الخطة / وحدات أو أسابيع:
- الحصص الأسبوعية ومدتها وأيامها إن أمكن:
- التقويم المعتمد أو اللقاءات الفعلية:
- عدد الطلبة وتنظيم الصف إن كان مهماً:
- الموارد والقيود ذات الصلة:
- تشخيص أو عوائق وصول معلومة:
- ما تريد الحفاظ عليه أو تحسينه:
- المخرج وحجمه: موجز / تقرير / جدول / ملف.
