# المرجع الأردني والسياق

## لكل وثيقة وظيفة

الإطار العام يحدد التوجهات؛ الإطار الخاص يحدد معايير ونتاجات المبحث؛ الكتاب ودليل المعلم يقدمان المحتوى وتسلسله وأمثلة تنفيذه؛ التعليمات والتقويم المدرسي يحددان القيود المعنية. لا تستنتج حظر استراتيجية من غيابها عن الكتاب، ولا تستبدل النتاج المقرر بكفاية عالمية عامة.

اجمع حسب المهمة: الإطار الخاص للمبحث والمرحلة، الكتاب/الدليل والطبعة، الخطة، نموذج المدرسة، التقويم المدرسي للسنة ونوع المدرسة، والحصص الفعلية. يكفي المتاح لبدء تحليل جزئي.

عند تعارض وثيقتين افحص الجهة والتاريخ والطبعة ونطاق التطبيق والتعديلات؛ اعرض التعارض. لا تفترض أن كل «أحدث» يلغي كل «أقدم». علّق الجزء المتأثر إن لم يوجد سند.

## سجل الدليل

| الحقل | ما يُسجل |
|---|---|
| source_id | معرّف محلي مثل S01؛ ليس رمز اعتماد |
| title / issuer / type | العنوان والجهة ونوع الوثيقة كما تظهر |
| grade / subject / semester / edition | من المحتوى؛ غير معلوم عند غيابه |
| location | مسار/رابط ورقم PDF والصفحة المطبوعة إن اختلفا |
| accessed_at | تاريخ الاطلاع منفصلاً عن تاريخ النشر |
| status | قرئ كاملاً / جزء ذو صلة / فهرسة فقط / تعذر الوصول |
| permitted_claim | ما يثبته المصدر فعلاً |

لا تستشهد بنتيجة بحث بوصفها الوثيقة الكاملة. حفظ مصدر عام لا يعني وجود بنك نتاجات لجميع الصفوف.

## الاسترجاع الاختياري من موصل المنهاج

عند توفر الأدوات:

1. `get_curriculum_overview` لمعرفة النطاق، ثم `list_books` لتثبيت الاسم الذي تعيده الأداة.
2. `get_book_structure` للغلاف والفهرس. قد تحتوي الفهرسة على `unknown` وأسماء غير عربية؛ تحقق من المحتوى.
3. `search_text` بمصطلح ومبحث وصف لتحديد الموضع، ثم `get_page_content` أو `get_lesson_content` للنص والسياق.
4. سجّل الاسم والصفحة والطبعة الظاهرة. الموصل نسخة مسترجعة لا تثبت وحدها آخر إصدار رسمي.

إن غابت الأدوات، استخدم المرفق أو المصدر الرسمي. لا تجعل غياب الموصل يمنع نقد الاتساق الداخلي.

## واقعية الصف: أسئلة تكييف وليست افتراضات

- الزمن: اللقاءات الأسبوعية ومدتها، البدء والانتهاء، أيام الحصص، الانقطاعات الفعلية، وقت الاختبارات والتحضير والانتقال.
- التنظيم: حجم الصف المثبت، المجموعات الممكنة، رؤية السبورة، توزيع الأدوات، جمع إجابة كل طالب دون تصحيح مرهق.
- الموارد: المتاح فعلاً، كلفة الطباعة، الاتصال، وبديل ورقي/بمواد مألوفة.
- التعلم: تشخيص ومعرفة سابقة ولغة تدريس وعوائق وصول معلومة. لا تنسب خصائص تعلم للجنسية أو اللجوء أو الجنس.
- الإتاحة: تعليمات واضحة، تكبير/قراءة عند الحاجة، واستجابة بديلة تحفظ المهارة المقاسة. إذا كان الهدف الكتابة، فالشفهي لا يقيس الكتابة نفسها.
- التجارب: مواد وتهوية وحرارة وأدوات وإشراف مناسب للعمر؛ عرض أو بيانات جاهزة عند تعذر نشاط مأمون. لا تُلزم شراء أجهزة أو حسابات طلابية.

## وسوم الادعاء

**متحقق:** نص مقروء وموضع ثابت. **استنتاج مهني:** تفسير مدعوم محدود. **مقترح:** تعديل جديد. **غير متحقق:** المرجع/الموضع/الطبعة غائب. **غير مذكور:** غائب عن كامل الجزء المراجع؛ لا يعني عدم التنفيذ.
